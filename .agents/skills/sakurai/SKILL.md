# スレスパ2の新キャラ設計レビュー

1. キャラの戦い方を一文で書く。プレイヤーが何を選び、何を失い、何を得るかを明確にする。
2. 初期デッキの固有カード2種と初期レリック1個で、固有ルールを初戦から試せる形にする。敵が攻撃するターンと攻撃しないターンなど、状況の違いで有力な選択が変わるかを確認する。
3. 初見のプレイヤーが、カード文、アイコン、実際の効果からルールを理解できるかを確認する。用語を統一し、迷った場面と何が分からなかったかを記録する。
4. 調整案は、威力・コスト・発動条件のどれを変えるかを示し、キャラ固有の強みを残せるかを確かめる。まずSTS2 Character Mod Creatorで表現できる形を試す。
5. GitHub Issueに「場面・観察したこと・次に試す変更」を短く残す。未プレイの段階では、観察結果の代わりに確かめたい仮説を書く。初版は [Issue #1](https://github.com/KAFKA2306/sts2/issues/1) で追う。
